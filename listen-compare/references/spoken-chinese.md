# 口语中文播报文体规范

写听稿之前读这份。它管的是**文体**——句子长什么样；SKILL.md 里的 ear rules
管的是**结构**(段落、路标、数字)。两层都过，稿子才算能听。

判断标准只有一条：**这句话像不像一个懂行的人，当面讲给你听？**
不像，就重写。书面报告腔的三个变体都不像：

- **PPT 腔**:名词短语没有谓语。"最大的共识：两份都认为……" 是幻灯片，不是人话。
- **公文腔**:进行、方面、层面、具有、存在。人说话不用这些字。
- **翻译腔**:长定语压垮句子。"写给投资人的、立场更谨慎的报告" 读到一半就断气。

## 七条硬规则

1. **冒号句改"是"字句。** 冒号读不出来。
   - ✗ 最大的分歧：市场能涨多快。
   - ✓ 那它们吵在哪儿呢？吵在能涨多快。

2. **每句都要有动词当主心骨。** 名词堆叠一律补上谓语。
   - ✗ 第三，渠道方面，便利店占了六成的销量，是决定性的渠道。
   - ✓ 第三件，渠道。六成的货是从便利店卖出去的，所以这仗打的就是便利店。

3. **自问自答带路。** 口语的路标不是标题，是问题。"那第二份怎么说？"、
   "这事儿重要吗？重要。" 每两三段用一次，多了油。

4. **判词说白话。** 书面判词换成有态度的短句。
   - ✗ 这个分歧要紧，因为它直接决定该不该加大投入。
   - ✓ 这一条最关键，因为它直接决定你现在要不要砸钱进去。

5. **对听众说"你"。** "先把结论放前面"、"方便你对着听"、"你要是只想记住一句话"。
   听稿是讲给一个人的，不是发布给一群人的。

6. **重要结论说两遍，换个说法。** 听众只听一遍，没有回看。结论第一遍正着说，
   第二遍用比喻或大白话再落一次："涨是肯定涨，问题是快慢。"

7. **连接词用口语的那套。** 那、其实、你看、也就是说、换句话说、再看、压根、
   顶多。禁用：综上、此外、与此同时、值得注意的是。
   语气词(呢、吧、嘛)每段最多一个，零个也行——多了显油，削弱可信度。

## 自检(交稿前必做)

把全稿**默读出声**一遍，三个检查点：
- 哪句换气不顺，拆短或重写；
- 哪句像在念 PPT，按规则 1、2 改；
- 全稿一个冒号引导句都不该剩，"方面/层面/进行"出现即删。

## 完整对照示例(反例来自本 skill 第一版真实翻车稿)

✗ 书面腔：
> 最大的共识：两份都认为即饮咖啡还会继续涨，低糖产品是主要的增量。
> 最大的分歧：市场能涨多快。星河说未来三年翻倍，蓝湾说只有五成上下。

✓ 口语版：
> 先把结论放前面。两份报告都同意一件事：即饮咖啡还会接着涨，涨的主要是低糖
> 产品。那它们吵在哪儿呢？吵在能涨多快。星河说，三年翻一倍；蓝湾说，顶多涨五成。

差别不在词汇量，在**句子的骨架**——口语版每句一个动作，先抛问题再给答案，
用"吵"这种有画面的动词代替"分歧"这种档案袋名词。
