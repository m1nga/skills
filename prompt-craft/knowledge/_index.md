# Marketing knowledge lookup

Resolve product context using SKILL.md's precedence. This index does not override
that order or create mandatory reads. Load a topic only when it changes the task's
result; use the relevant sections rather than the whole library.

| Reference | Use when |
|---|---|
| [asr-corrections.md](asr-corrections.md) | Dictated input contains likely transcription errors; combine with an applicable user dictionary |
| [copywriting.md](copywriting.md) | A copy prompt needs concrete headline, hook or CTA guidance |
| [video.md](video.md) | A video prompt needs pacing, scene or sound decisions |
| [platforms.md](platforms.md) | Channel constraints matter; verify current official limits before relying on cached specs |
| [campaigns.md](campaigns.md) | Campaign prompts need an audience, action or measurement structure |
| [brand-voice.md](brand-voice.md) | Supplied tone requirements need clarification or examples |
| [frameworks.md](frameworks.md) | A framework fits the specific problem, not merely because it exists |
| [common-failures.md](common-failures.md) | Reviewing a plausible failure in a consequential or reusable prompt |
| [user-context.example.md](user-context.example.md) | The user wants to set up optional reusable brand context |

These are maintained reference ideas, not a command to run a fixed ceremony.
Their example brands, numbers and outcomes are not user facts or measured promises.
Current user intent and SKILL.md's scope control how the material is used.
