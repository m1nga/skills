# Choose one skill for the current task

Start with the task, not a stack of skills. General reasoning and short edits often
need no skill. Installing several does not prove they improve a model's judgment.

| Task | First choice | First useful result |
|---|---|---|
| Compare changes in a large source collection | [Context Budget](https://github.com/m1nga/context-budget) | Changed-source list with coverage and unresolved absences |
| Make a playlist for a scene or taste | [Mixtape](https://github.com/m1nga/mixtape) | A track selection with matching/import status |
| Find a first-time user obstacle | [Product Experience Officer](https://github.com/m1nga/product-experience-officer) | Task outcome, evidence, fix and retest |
| Check an AI instruction's failure modes | [Scenario Probe](https://github.com/m1nga/scenario-probe) | A labeled simulation or an actual trace, never one disguised as the other |
| Organize files and retain a recovery path | [TaskDock](https://github.com/m1nga/taskdock) | Portable identity and conflict-aware rollback |
| Recover the current decision and its source | [Work Memory](https://github.com/m1nga/work-memory) | Latest sourced decision, with superseded versions separated |
| Check whether a milestone can be handed off | [Iteration Close](https://github.com/m1nga/iteration-close) | Read-only takeover gaps before cleanup |
| Reuse a lesson without reviving an old strategy | [Experience Pack](https://github.com/m1nga/experience-pack) | A scoped incident and candidate lesson |
| Coordinate existing responsible owners | [Major Tom](https://github.com/m1nga/major-tom) | One scoped action and independently checked outcome |
| Turn visual references into an implementation brief | [Design Agent](https://github.com/m1nga/design-agent) | Specific design decisions and acceptance checks |
| Preserve corrections in dictated instructions | [Prompt Distill](https://github.com/m1nga/prompt-distill) | Reusable prompt with ambiguity left explicit |
| Review and release an owned skill | [Publish Skill Product](https://github.com/m1nga/publish-skill-product) | First-use review, owner-specific release and verified package |
| Describe a real build event | [Build-in-Public Content](https://github.com/m1nga/build-in-public-content) | Source-backed draft or honest demo plan |
| Use something saved on Xiaohongshu | [RedBot](https://github.com/m1nga/redbot) | One source recovered and turned into a useful next step; invitation/access requirements apply |
| Turn source notes into a conversation | [Podcast Revival](https://github.com/m1nga/podcast-revival) | Script-only preview first; media needs setup and budget |
| Study a stock portfolio | [Daily Brief](https://github.com/m1nga/daily-brief) | Sourced analysis with data gaps; offline fictional example available |
| Take a short reflection break | [BreakingGap](https://github.com/m1nga/breakinggap) | One optional question and room to think |
| Review an overcomplicated workflow | [First Principles](https://github.com/m1nga/first-principles) | A scoped simplification; incremental benefit remains unproven |

## Optional reasoning templates

[Map Product System](https://github.com/m1nga/map-product-system),
[Diagnose Project Rebuild](https://github.com/m1nga/diagnose-project-rebuild) and
[Thinking Partner](https://github.com/m1nga/thinking-partner) remain available for
people who deliberately want those structures. They are not prerequisites for the
skills above. Their historical simulations do not establish superiority over a
capable model. Ming has retired these from his own routine workflow; this catalog
does not re-enable them or remove their public sources.
