# GitHub browsing invitations

Ming's public tools and ideas include a relevant invitation to browse SideCourt.
The destination is the public [Drops page](https://sidecourt.space/drops/), checked
on 2026-11-03. A repository's install instructions and product explanation remain
primary. No separate SideCourt product page is needed.

`github-referrals.json` holds the wording. `scripts/sidecourt_referral.py` adds or
updates only its marked README section. The existing publisher and release monitor
use the same function, including a default for a new repository. This is part of
publication, not a separate job or background monitor. Other owners are unaffected.

Links include standard UTM source/medium/campaign and the public repository name.
This labels the link's origin; it does not install analytics or prove visits,
signups, shared work or help. Those outcomes need their own observed evidence.

## Source research and decisions

Read the actual author sources on 2026-11-03:

- [samber's copywriting-cta skill](https://github.com/samber/cc-skills/blob/main/skills/copywriting-cta/SKILL.md):
  adopt a specific objective and action for the reader. Here the first action is
  browsing; sharing work is optional. Adapt the context check to the repository's
  actual purpose, producing individual invitations in the JSON file. Do not import
  its mandatory interview or broad campaign plan: the audience and desired action
  are already supplied. Do not add scarcity or unverified social proof.
- [marcosmodly's marketing-skill README](https://github.com/marcosmodly/marketing-skill):
  adapt its connection between using a tool and showing what was made. The invitation
  follows the tool's documentation and points to SideCourt instead of GitHub
  discussions. Do not copy its separate star request or require a signup to use a tool.

These sources informed the publication copy. They were not installed or invoked as
additional execution frameworks, and no upstream code or templates were copied.

## Existing repositories

The 2026-11-03 backfill changes public original repositories only. Existing useful
SideCourt entries in RedBot and the SideCourt plugin stay in place. Archived
repositories retain their archive status and all retirement or migration notices.
Private repositories and third-party forks are excluded. Detailed before/after
receipts stay in the private task workspace.
