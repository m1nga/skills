# RedBot 1.9 local computation dependencies

## Semantic matching

The app serves its own pinned Transformers.js **3.8.1** and ONNX Runtime Web **1.22.0-dev.20250409-89f8206ba4** JavaScript, module and WASM files from `app/vendor/transformers/`. There is no runtime JavaScript import from a public CDN. [assets.lock.json](app/vendor/transformers/assets.lock.json) records exact upstream package URLs, observed SHA256 and byte counts; the semantic worker tests verify the prepared bytes. Apache-2.0 and MIT license files are adjacent. These hashes establish repeatable assets, not an independent upstream security audit.

Before local self-hosting or frontend packaging, run `python3 scripts/prepare-runtime.py`. The 21,596,019-byte WASM is a reconstructable resource excluded from source tracking. The preparer downloads only this asset from [the fixed public source commit](https://raw.githubusercontent.com/m1nga/skills/278e12261fd7f4fefc2a632138665510ccbcad6e/redbot/product-root/source/app/vendor/transformers/ort-wasm-simd-threaded.jsep.wasm), validates the lock manifest's byte count and SHA256, then atomically installs it. Existing verified files skip network access; an invalid existing file requires explicit `--repair`. Download or validation failures leave the previous file intact. HTTPS uses default certificate verification, a 15-second socket timeout and a 120-second transfer deadline (a pending socket read may add up to 15 seconds); no automatic retry or model execution occurs. The prepared WASM remains served from the app's own origin and must be included in the deployment. Keep the lock and licenses; never substitute `latest` silently.

Public model: [Xenova/paraphrase-multilingual-MiniLM-L12-v2](https://huggingface.co/Xenova/paraphrase-multilingual-MiniLM-L12-v2/tree/2c4055b12046f11709e9df2c122e59ffbdc2f900), revision **2c4055b12046f11709e9df2c122e59ffbdc2f900**, q8 quantization, mean pooling and normalized vectors. Its [Sentence Transformers base-model card](https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2) identifies Apache-2.0 licensing and a 128-token sentence-transformer window. The first opt-in downloads model assets from that fixed revision; quantized weights are about 118MB and the tokenizer about 17MB. Browser storage/cache may be evicted; first use and cache misses require network access. Model inference is local; query, saved text, notes and video OCR/transcripts are not sent to a remote inference API. This has no paid API fee, but consumes visitor CPU, memory, storage and bandwidth.

All active rows are considered. Text and queries use 100-token windows with 20-token overlap, processed in batches of at most four. The pinned tokenizer config declares a 512-token maximum while tokenizer JSON contains a 128-token truncation configuration; the application conservatively stays below both. Save text is not cut to a fixed character prefix. Maximum chunk similarity ranks candidates and does not verify that their methods meet a user’s requirements. Speech/OCR-derived text remains fallible source material.

IndexedDB vector keys bind hashed account scope, model revision, quantization/pooling/chunking identity and chunk-text SHA256. Stored entries contain numeric vectors and hashed scope, not raw source text. Completed batches can be reused after cancellation. A successful full scan prunes obsolete entries only in its own scope. Storage failure falls back to local computation without persistence and is exposed in returned coverage. Browser-managed public model caches are separate from account-scoped vectors.

The client must set the active account scope, cancel stale jobs and clear the old scope when required. Default scope is a random session identifier. Scope isolation is namespacing, not encryption or a secure-erasure guarantee: another already-open tab can recreate same-scope vectors after deletion. Worker tasks serialize within one worker; there is no global cross-tab lock. Cancellation takes effect between batches and cannot interrupt a WASM call already executing. Local hosting must serve `.mjs` as JavaScript and `.wasm` as `application/wasm` and include nested vendor assets in its deployment.

## Verification boundaries

Semantic retrieval ran with the actual fixed model in the official Transformers.js 3.8.1 **Node** distribution and native ONNX Runtime CPU **1.21.0**, on synthetic text: 351 rows/369 chunks, relevant final long-text chunk first for Chinese synonyms and English paraphrase, repeat-cache hits, account scopes and cancellation/resume. Node’s native runtime is a test dependency, not the browser’s shipped runtime. fake-indexeddb tests exercise transaction behavior, concurrent connections, scoped pruning, reopening and failure fallback; they do not establish browser disk persistence.

Browser worker/WASM loading, the deployment’s MIME/asset serving, persistent vectors after browser restart, first-download UX and two real account sessions need separate live browser acceptance. No private saved library was used for the model test. Real video-tool validation used newly authored speech/title-card media; it does not establish Xiaohongshu download availability, Chinese recognition accuracy or complete visual understanding.

## Display language

Derived Chinese summaries and briefs use the self-hosted `opencc-js` **1.4.2** traditional-to-simplified dictionary bundle from [its author repository](https://github.com/nk2028/opencc-js). `app/vendor/opencc/assets.lock.json` records the fixed npm tarball integrity and installed file SHA256 values. MIT and Apache-2.0 license texts are included. Original source text is preserved; code spans and URLs are excluded from conversion. The 109,333-byte converter performs character/phrase conversion locally; it does not correct speech-recognition errors or make model calls. No runtime CDN script is loaded.
