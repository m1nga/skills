# Local video reading

`POST /api/video {"id":"saved note id"}` starts a `video` job; poll the existing connection/library endpoints. `POST /api/cancel-video` cancels it. Only a verified signed-in visitor's imported saves can be read; detail uses their isolated authenticated browser connector. No owner cookie/session reuse, CAPTCHA bypass, cloud inference or paid API. This is normal logged-in page reading via an **unofficial** connector, not an official Xiaohongshu API or a guarantee of download rights.

Run `python3 connector/setup_video.py` explicitly on macOS. It prepares a project-local environment/model/OCR executable, without changing system settings or restarting the service. Requires installed whisper.cpp **1.9.2** at the pinned Homebrew cellar path and Xcode Swift/Vision. The next explicit service start reads `connector/video-runtime.local.json`; preexisting environment variables take precedence. No automatic dependency/model updates occur at runtime.

Pins: imageio-ffmpeg **0.6.0** (BSD-2-Clause wrapper, bundled FFmpeg **7.1 GPL-2.0-or-later**, verified with this exact binary’s `-L`; retain its corresponding source/license obligations on redistribution); whisper.cpp **1.9.2** MIT; ggerganov/whisper.cpp model revision **5359861c739e955e79d9a303bcbc70fb988958b1**, multilingual tiny `ggml-tiny.bin`, SHA256 **be07e048e1e599ad46341c8d2a135645097a538221678b7acdd1b1919c6e1b21**, MIT. Model [author source](https://huggingface.co/ggerganov/whisper.cpp/blob/5359861c739e955e79d9a303bcbc70fb988958b1/ggml-tiny.bin); [whisper.cpp](https://github.com/ggml-org/whisper.cpp/tree/v1.9.2); [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg/tree/v0.6.0). Apple Vision is the operating-system OCR framework, not an independently redistributed model. Its OS revision is a platform dependency.

Whisper returns timestamped speech segments. Up to 12 uniform frames (minimum spacing 2 seconds, 960px wide) go through Apple Vision Chinese/English OCR. This does **not** understand objects, gestures, scenes, relationships, edits or visual instructions; `visualUnderstanding:false`, `coverage.visual:not_performed` always. Frame timestamps identify sample positions, not complete visual coverage. Speech recognition can mistranscribe or hallucinate, and tiny's Chinese accuracy is limited. `complete` means the requested ASR and sampled OCR stages executed, never full semantic understanding.

Hard bounds: HTTPS CDN allowlist (`*.xhscdn.com`, `*.xiaohongshu.com`), public-IP resolution pinned to each TLS request, revalidation at every redirect, 3 redirects, no cookies, 100MiB download, 600-second duration checked against actual decoding, 900-second pipeline deadline and 10-second network read timeout. No media URLs or files are served to the client. Temporary video/audio/frames are deleted; account-local text results persist with the existing seven-day session lifecycle. Cache binds source media ID/hash, duration/stream characteristics, note revision/text, pipeline/model digest and account directory. Signed URL rotation does not invalidate unchanged content. A single session job prevents concurrent analysis within an account; a process-wide single video slot limits the whole service to one local video pipeline, with retryable `video_busy` HTTP 429 for another account; CPU/RAM/storage/bandwidth are local costs, not zero cost.

Diagnostic codes: `video_setup_required`, `video_model_mismatch`, `video_source_unavailable`, `video_protected`, `video_duration_limit`, `video_too_large`, `video_url_not_allowed`, `video_redirect_limit`, `video_download_failed`, `video_tool_failed`, `video_timeout`, `video_cancelled`. Stage errors stay explicit under `videoAnalysis.coverage`; fatal failures include `videoAnalysis.error` and job failure. No signed URL or raw upstream exception is returned. Setup does not read saved private libraries or existing accounts. Tests use newly authored synthetic speech/card media, separately from mocked unit checks.

## Actual local verification (2026-11-04)

40 Python tests passed (connector/session tests plus video security/unit tests). A newly authored 3.84-second MP4 combined system-generated synthetic English speech with an original title card. Real whisper.cpp recognized “Redbot reads this locally, the Blue Notebook costs $12.” and real Apple Vision recognized “LOCAL VIDEO TEST 42” in both sampled frames. `video-evidence/real-analysis.json` records the actual result. This validates decoding, ASR timestamps, frame extraction and OCR with real tools; it does not validate Xiaohongshu network delivery or Chinese recognition accuracy. No private save or owner account was read.

The connector safely serves public nested `app/vendor/` assets. `.mjs` is JavaScript and `.wasm` is `application/wasm`; resolved files must stay inside APP, traversal/hidden paths and symlink escapes are rejected. Runtime configuration emitted by setup uses absolute paths, so copying `video-runtime.local.json` into an operator-approved host snapshot preserves model/tool locations without another installation.

A separately authorized 2026-11-04 source-chain trial used only the designated existing owner's copied cookie in an independent temporary connector. The normal signed-in identity check returned no confirmed login or user ID on two bounded attempts, so the trial stopped **before** requesting any selected note detail or media. It did not bypass login, change the original cookie/library, mint a bearer on the running server, restart the service, or access another visitor's account. Temporary data and source processes were cleaned. Actual Xiaohongshu media delivery remains unverified pending normal login restoration. Sanitized task-private evidence records original-file checksum equality and excludes saved IDs, titles, URLs, tokens and source text.

Refresh semantics: a failed verification/detail/media/processing refresh preserves the last complete `videoAnalysis` (including its original `readAt` and `sourceVersion`) and records `videoAnalysis.lastRefreshError = {code, at, retainedPrevious:true}`. The latest job still fails; retained evidence is not presented as a newly successful read. A new partial result also cannot erase a previous complete result. A successful subsequent refresh clears the prior refresh error. First-time failures remain explicitly incomplete.

Source metadata may expose an HTTP CDN link. Only a credential-free allowlisted CDN host with the default HTTP port is upgraded to HTTPS; the actual request still undergoes public-IP/TLS/redirect validation. Other HTTP origins/ports are rejected. OCR confidence is returned numerically in the range 0–1. Public capabilities distinguish optional local model inference from zero cloud inference calls.
